# Screenshot Assets Directory

Place actual screenshot image files for each module in this folder:

- `mod-user.png` - User Management table & create dialog
- `mod-entity.png` - Entity Management view
- `mod-branch.png` - Branch Management view
- `mod-departments.png` - Departments view
- `mod-division.png` - Divisions view
- `mod-position.png` - Positions view
- `mod-job-title.png` - Job Title view
- `mod-user-access.png` - User Access direct permissions screen
- `mod-role-permissions.png` - Role Permissions matrix screen

The manual will automatically load these images. If an image is not present yet, a high-fidelity visual UI mockup will be shown as an interactive fallback with lightbox preview support.
