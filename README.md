# GGC HRIS - Admin Settings User Manual (Vuetify Edition)

A modern, component-driven user manual built with **Vue 3**, **Vuetify 3**, **Vite**, and **TypeScript**.

## 🚀 How to Run Locally

### 1. Development Server
Run the Vite development server with hot module replacement:

```bash
cd vuetify-manual
npm run dev
```

Open your browser at the displayed local URL (typically `http://localhost:3000` or `http://localhost:5173`).

---

### 2. Production Build & Preview
To build for production and preview the optimized build:

```bash
cd vuetify-manual
npm run build
npm run preview
```

---

## 🎨 Features
- **Vuetify 3 Material Design Components**: `v-app-bar`, `v-navigation-drawer`, `v-card`, `v-table`, `v-chip`, `v-alert`, `v-avatar`.
- **9 Core Admin Modules**: Fully documented form fields, rules, data types, and workflows.
- **Organizational Hierarchy Visualizer**: Parent-to-child sequence banner (`Entity → Branch → Department → Division → Position → Job Title → Role Permissions → User`).
- **Interactive Live Search**: Filters modules, fields, descriptions, and permission keys in real-time.
- **Theme Switching**: Dark / Light theme toggle.
- **Print & Export to PDF**: Tailored print styles hiding headers and drawers when exporting (`Ctrl + P`).
